Difference Between Constructor and Method in Python
Constructor							Method
A constructor initializes an object.			A method performs an operation using the object.
Constructor name is always __init__().			A method can have any valid name.
It is called automatically when an object is created.	It must be called explicitly using the object.
It normally initializes instance properties.		It normally reads or modifies properties.
Usually runs once during object creation.		Can be called multiple times.
It does not return a value explicitly.			It can return a value.
